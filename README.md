# Employee Performance Analysis 💼

This project analyzes employee salary, work hours, experience, and performance scores using Microsoft Excel.

## Analysis Performed
- Descriptive Statistics
- Correlation Analysis
- Regression Analysis
- Data Visualization

## Key Insight
Employees with more experience and work hours showed higher performance scores.
